# front 후속 확인 요청 체크리스트
---

## 어떤 문서인가요?

> 백엔드 쪽 기준선은 대부분 정리된 상태입니다.
> 이 문서는 front에서 실제 화면과 동작 결과를 확인할 때 쓰는 체크리스트입니다.
> 가능한 한 front가 직접 확인해야 하는 내용만 남겼습니다.

## 체크리스트

### #32 매장 계정 생성 후 화면 이동

- [ ] 회원가입이 끝나면 바로 `partner/dashboard/`로 이동하는지 결과 확인
- [ ] 가입이 끝난 뒤 다시 가입 화면에 머무르지 않는지 결과 확인

**설명**
- 이 부분은 PM과 이미 합의된 내용입니다.
- 지금은 어디로 갈지 다시 정하는 단계가 아니라, 실제로 대시보드 직행이 되는지 결과를 확인하는 단계입니다.

### #123 재추천 화면과 결과

- [ ] 처음 추천 화면에 `재추천` 버튼과 `미용사 상담` 버튼이 자연스럽게 보이는지 결과 확인
- [ ] 고객이 아무 추천도 고르지 않고 상담도 고르지 않았을 때만 재추천이 가능한지 결과 확인
- [ ] 재추천 시 기존 5장 대신 새로운 5장을 전부 다시 출력하는지 결과 확인
- [ ] 재추천 뒤에는 `재추천` 버튼이 사라지고 `미용사 상담`만 남는지 결과 확인
- [ ] 재추천 결과를 새로 불러온 5장으로 화면 전체가 자연스럽게 바뀌는지 결과 확인

**설명**
- 재추천은 처음 추천에서 마음에 드는 결과가 없었을 때만 한 번 더 보여주는 흐름입니다.
- 이때는 기존 결과를 조금 고치는 것이 아니라, 새로운 5장을 다시 보여주는지 확인해주시면 됩니다.
- 재추천 뒤에는 버튼 구성과 카드 화면이 그 흐름에 맞게 자연스럽게 바뀌는지 봐주시면 됩니다.

### #140 기본 에러 응답 표시

- [ ] 지금 backend가 보내는 기본 에러 응답이 front 화면에서 문제 없이 처리되는지 결과 확인
- [ ] 입력 오류와 일반 오류가 화면에서 너무 헷갈리지 않게 보이는지 결과 확인
- [ ] 공통 에러 형식이 나중에 들어오기 전까지도 현재 방식으로 임시 운영 가능한지 결과 확인

**설명**
- 지금은 화면에서 받는 오류가 너무 어렵지 않게 보이는지 확인하는 항목입니다.
- 입력을 잘못 넣었을 때와 다른 이유로 실패했을 때가 화면에서 너무 헷갈리지 않게 나뉘는지만 봐주시면 됩니다.
- 앞으로 더 정리된 오류 형식이 들어오더라도, 지금 화면이 크게 흔들리지 않는지 함께 확인해주시면 됩니다.

### #141 로그인 유지와 만료 후 화면 흐름

- [ ] 로그인 후 24시간이 지나면 자동으로 다시 로그인해야 하는 흐름이 자연스럽게 보이는지 결과 확인
- [ ] 24시간이 끝난 뒤 다시 로그인 화면으로 자연스럽게 이동하는지 결과 확인
- [ ] 만료됐을 때 사용자에게 보여줄 문구가 이해하기 쉬운지 결과 확인
- [ ] 만료 후 화면이 어색하게 멈추지 않고 다시 로그인 흐름으로 이어지는지 결과 확인

**설명**
- 이 항목은 로그인 유지 시간이 24시간이라는 기준을 front 화면에서 자연스럽게 보여주는지 확인하는 항목입니다.
- front에서는 저장 방식 자체를 다시 설계하기보다, 24시간이 지나면 다시 로그인하도록 화면이 자연스럽게 이어지는지만 봐주시면 됩니다.
